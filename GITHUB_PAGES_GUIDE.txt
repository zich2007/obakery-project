O.BAKERY PROJECT 5.0 - GitHub 업로드 안내

1. GitHub에서 새 저장소를 생성합니다.
   Repository name: obakery-project
   Public 또는 Private 모두 가능 (GitHub Pages 무료 공개 배포는 공개 저장소 권장)
   Add a README file은 체크하지 않아도 됩니다.

2. 저장소 첫 화면에서 Add file > Upload files를 선택합니다.

3. 이 폴더 안의 index.html, README.txt, GITHUB_PAGES_GUIDE.txt를 업로드하고 Commit changes를 누릅니다.

4. 저장소 Settings > Pages로 이동합니다.
   Build and deployment: Deploy from a branch
   Branch: main
   Folder: /(root)
   Save를 누릅니다.

5. 잠시 기다린 뒤 Settings > Pages에 표시되는 사이트 주소로 접속합니다.
   일반적인 주소 형식: https://GITHUB_USERNAME.github.io/obakery-project/

주의:
- 업로드할 때 ZIP 파일 자체가 아니라 압축을 푼 내부 파일을 업로드합니다.
- index.html은 저장소 최상위(root)에 있어야 합니다.
- GitHub Pages는 정적 호스팅입니다. 별도 AI 서버를 연결하지 않으면 사진 분류는 파일명 기반 추천/사용자 수동 확인 방식입니다.
- 업로드된 사진과 프로젝트 저장 파일은 사용자의 브라우저/기기에 저장하는 구조이며, 브라우저 데이터 삭제 전 .obakery 파일로 백업하세요.
- AI 서버 주소나 API 비밀키를 HTML에 직접 입력하지 마세요.


[PDF 기능]
PPTX 파일 만들기와 별도로 PDF 파일 만들기 버튼을 사용할 수 있습니다. PDF는 동일한 슬라이드 흐름과 16:9 디자인으로 생성됩니다. 인터넷 연결이 필요합니다.
