LOCAL PROJECT

사진은 브라우저에서 미리 확인하고, 프로젝트 파일에 포함해 기기에 저장할 수 있습니다.

실제 이미지 AI 분류를 사용하려면 호환 API 서버가 필요합니다. 주소가 없으면 파일명 기반 추천과 수동 확인 모드로 작동합니다.

업로드된 사진이 없습니다.
분류 항목: 재료 준비 · 믹싱 · 반죽 상태 · 1차 발효/접기 · 분할/벤치타임 · 충전 · 성형 · 2차 발효 · 굽기 전 마무리 · 굽기 · 완성품 · 관능평가 · 기타

프로젝트 파일은 사진과 작성 내용을 포함합니다. 로컬 자동 저장은 브라우저별 저장 공간 제한을 받을 수 있으므로 .obakery 파일로 백업하세요.

01제출자 정보

PPT 표지와 제품 소개에 표시할 본인 정보를 입력하세요. 입력하지 않은 항목은 PPT에 표시되지 않습니다.

02제품 정보

과제의 기본 제목과 실습 품목을 입력하세요.

재료표 · 배합표 이미지 첨부직접 제작한 재료표, 배합표, 베이커스 퍼센트 정리 이미지를 등록하세요.

03실습 사진

반죽·공정 사진과 완성품 사진 등 과제에 사용할 이미지를 등록하세요.

실습 사진 선택 사진 수량 제한 없이 여러 장을 한 번에 선택할 수 있습니다.
선택된 사진 0장

04제조 과정 기록

각 공정을 단계별로 기록하세요. 작업 내용뿐 아니라 반죽 상태, 온도, 시간, 주의사항까지 정리할 수 있습니다. 제품에 맞지 않는 단계는 삭제하고 필요한 단계는 추가하세요.

작성 팁: 무엇을 했는지 → 어떤 상태였는지 → 온도·시간 등 조건은 어땠는지 → 주의할 점은 무엇인지 순서로 작성하면 좋아요.

05관능평가

아래 항목을 참고해 제품을 직접 관찰하고 맛본 결과를 서술형으로 작성하세요. 예시는 작성 방향을 돕기 위한 문장이므로 제품에 맞게 수정하면 됩니다.

내부 평가

제품을 잘라 내부의 조직과 상태를 확인하고 평가합니다.

외부 평가

제품의 겉모양과 굽기 상태, 형태적 완성도를 평가합니다.

관능평가 참고 이미지 첨부단면, 기공, 외형 등 평가 내용을 뒷받침하는 사진을 등록하세요.

06고찰

제조 결과의 원인과 개선 방향을 정리하세요.

고찰 참고 이미지 첨부실패 사례, 수정 전후 비교, 실습 결과 등을 보여주는 이미지를 등록하세요.

PPTX 생성은 인터넷 연결이 필요합니다. 사진과 작성 내용은 이 브라우저 안에서 처리되며 별도 서버로 전송되지 않습니다.
