O.BAKERY PROJECT 5.16
PDF 페이지 잘림 및 제목 분리 수정 버전

변경 사항
- PDF 페이지 분할 시 섹션 제목만 페이지 하단에 남는 현상 방지
- 관능평가 등 표의 행이 페이지 경계에서 잘리는 현상 완화
- 공정 카드와 사진 블록이 가능한 한 페이지 안에서 유지되도록 페이지 분할 규칙 보강
- PDF 출력 여백과 페이지 분할 회피 선택자 조정

설치
1. ZIP 압축을 풉니다.
2. index.html을 기존 GitHub 저장소 루트의 index.html과 교체합니다.
3. GitHub에 커밋한 뒤 Safari/Chrome에서 사이트를 새로고침합니다.

참고
JavaScript 문법 검사는 통과했으나, 실제 iPad Safari 및 PDF 파일 출력 결과는 사용자 환경에서 확인이 필요합니다.
