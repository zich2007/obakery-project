O.BAKERY PROJECT 5.18
PDF 생성 오류 진단 및 안정화

수정 사항
- html2pdf.js CDN을 3개 경로로 순차 시도
- 스크립트가 로드되어도 html2pdf 전역 함수가 없는 경우를 별도로 감지
- 문서 로드, 웹폰트 준비, 이미지 로드/디코드 완료 후 PDF 생성
- 캔버스 해상도를 1.5로 조정하고 압축 옵션 적용해 메모리 부담 완화
- 오류를 숨기지 않고 실제 예외 메시지를 사용자에게 표시
- 생성 실패 시 새 창을 닫고 버튼 상태 복구
- 성공 시 직접 PDF 파일 다운로드

설치
1. ZIP 압축을 풉니다.
2. index.html을 GitHub 저장소 루트의 기존 index.html과 교체합니다.
3. GitHub에 커밋하고 사이트를 새로고침합니다.
4. PDF 파일 만들기를 다시 실행합니다.

참고
JavaScript 문법 검사만으로 실제 브라우저 PDF 생성 성공을 보장할 수 없습니다.
실제 오류가 다시 발생하면 표시된 '오류 내용'을 보내 주세요. 해당 원인을 더 정확히 수정할 수 있습니다.
