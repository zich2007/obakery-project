O.BAKERY PROJECT 5.17
PDF 섹션 제목 잘림 방지 강화 버전

5.16의 페이지 분할 규칙만으로는 html2pdf.js의 캔버스 기반 페이지 자르기에서
브라우저의 break-inside / page-break-inside 규칙이 일관되게 적용되지 않을 수 있었습니다.

5.17 변경:
- html2pdf pagebreak.before에 h2를 지정해 주요 섹션을 새 페이지에서 시작
- 첫 번째 제품 정보 섹션은 표지 바로 다음에 이어지도록 예외 처리
- 각 섹션 제목과 바로 다음 내용이 서로 다른 페이지에 분리되는 현상 완화
- 표 행, 공정 카드, 사진 블록의 분할 회피 규칙 유지

설치:
1. ZIP 압축 해제
2. index.html을 GitHub 저장소 루트의 기존 파일과 교체
3. 커밋 후 사이트에서 강력 새로고침
4. 기존에 저장해 둔 PDF가 아닌 새로 생성한 PDF로 확인

주의:
이번 수정은 섹션마다 새 페이지를 시작하는 방식이라 PDF 페이지 수가 늘어날 수 있습니다.
JavaScript 문법 검사는 통과했으나 실제 iPad Safari PDF 출력은 확인이 필요합니다.
