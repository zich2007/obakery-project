O.BAKERY PROJECT 5.20
메인 빵 이모지 랜덤 변경 및 다크모드

변경 사항
1. 메인 화면의 빵 이모지를 터치/클릭하면 다른 빵·베이커리 이모지로 무작위 변경됩니다.
2. 상단에 다크모드/라이트모드 전환 버튼을 추가했습니다.
3. 선택한 테마는 브라우저에 저장되어 다음 방문에도 유지됩니다.
4. PDF 보고서는 기존처럼 흰색 인쇄용 테마로 생성되며, 사이트 다크모드 설정의 영향을 받지 않습니다.
5. 기존 재료표, 프로젝트 저장/불러오기, PPTX/PDF 생성 기능은 5.19 기반으로 유지했습니다.

설치
- ZIP 압축을 풀고 index.html을 GitHub 저장소 루트의 기존 파일과 교체한 뒤 커밋하세요.
- iPad Safari에서는 사이트를 새로고침한 후 상단의 다크모드 버튼을 눌러 확인할 수 있습니다.
