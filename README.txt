O.BAKERY PROJECT 5.11
=====================

수정 내용
- 제조과정기록의 기본 공정 페이지와 해당 공정의 보조 사진 페이지를 하나로 통합했습니다.
- 공정 기록 텍스트는 페이지 오른쪽에 배치하고, 보조 사진은 왼쪽에 배치합니다.
- 보조 사진이 1장이면 크게, 2장 이상이면 2열 갤러리로 한 페이지에 배치합니다.
- 사진 설명은 해당 이미지의 설명/캡션이 입력되어 있을 때 표시합니다.
- 온도, 시간, 주의사항 등은 입력된 항목만 표시합니다.
- 이전 버전에서 유지한 원본 사진 비율, 재료표 이미지 제목 제거 및 확대, 공란 숨김 기능도 유지했습니다.

검증
- JavaScript 문법 검사 통과
- HTML 중복 ID 검사: 없음
- 제조 공정별 기본 기록과 보조 사진을 동일 슬라이드에 생성하도록 변경 확인
- 실제 PowerPoint 앱에서의 렌더링은 사용자 기기에서 최종 확인 필요

배포
