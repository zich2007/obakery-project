O.BAKERY PROJECT 5.22 — 무료 OCR 개선 버전

5.21 최신 기능을 유지하면서 OCR 처리만 개선했습니다.

무료 개선 기능
- Canvas 기반 이미지 확대(최대 2.5배)
- 그레이스케일 및 명암 대비 보정
- 흑백 임계값 처리
- 보정 원본/명암/흑백 3가지 이미지로 다중 인식
- Tesseract 인식 신뢰도(confidence)를 비교해 우선 결과 선택
- 나머지 인식 결과도 참고 영역에 표시
- 재료표는 표 형태 인식에 유리한 페이지 모드, 제조공정은 흩어진 문장 인식에 유리한 페이지 모드를 사용
- '재료명 500'처럼 단위 g가 빠진 인식 결과도 추출하도록 재료 파서 개선
- 기존 검토 후 반영 방식 유지

사용법
1. 재료표 또는 제조공정 사진을 선택합니다.
2. '사진 보정 및 다중 인식 사용'을 켠 상태로 글자 인식을 실행합니다.
3. 첫 번째 선택 결과와 다른 인식 결과를 비교합니다.
4. 틀린 숫자/재료명은 결과 칸에서 직접 수정합니다.
5. 반영 버튼을 눌러 기존 입력 영역에 추가합니다.

비용 및 개인정보
- 유료 API, API 키, 별도 서버 비용 없음.
- OCR은 브라우저에서 실행됩니다.
- Tesseract.js와 한국어/영어 언어 데이터 최초 다운로드에는 인터넷이 필요합니다.
- 사진 자체를 외부 AI 분석 API로 전송하지 않습니다.

주의
- 다중 인식은 결과를 비교하는 방식이며 정확성을 보장하지 않습니다.
- 글씨가 흐리거나 표 선이 글자를 가리는 경우, 촬영 각도가 심하게 기울어진 경우에는 오인식할 수 있습니다.
- JavaScript 문법 검사 통과. 실제 iPad Safari OCR 성능과 인식률은 사용자의 사진으로 확인해야 합니다.
