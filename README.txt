O.BAKERY PROJECT 5.2.3
- 전체 실습 일괄 업로드에서 이미지 이외 파일도 함께 선택 가능
- 이미지 파일은 기존 사진 분류 기능으로 전달
- PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX, ZIP 등 기타 파일은 첨부파일 목록에 표시
- 첨부파일 개별 삭제 가능
- .obakery 프로젝트 저장/불러오기에 원본 파일 데이터 포함
- 사진 분류 및 기존 5.2.2 사진 삭제 기능 유지
참고: 기타 문서 파일은 .obakery 프로젝트에 원본으로 보관되며, PPTX에 문서 내용을 직접 삽입하지 않고 파일 첨부 목록으로 관리합니다.
