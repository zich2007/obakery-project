O.BAKERY PROJECT 6.2 — AI 사진 분석 안정화

이번 버전은 6.1 기능을 유지하면서 사진 분류 및 제조과정 사진 기록을 1장씩 순차 처리합니다.

변경 사항
- 사진별 단일 요청으로 처리하여 한 요청에 여러 이미지가 몰리는 현상 완화
- 일시 오류(네트워크, 408, 429, 500, 502, 503, 504) 자동 재시도: 2초, 5초, 10초 간격
- 실패한 사진만 별도 재시도
- 성공한 사진 결과는 실패가 발생해도 화면에 유지
- 진행 상태에 성공/실패 수 표시
- Gemini 모델 및 API Key 환경 변수는 기존 설정 유지

배포 주의
- 아직 GitHub에 업로드하거나 Vercel에 배포하지 않은 로컬 제작본입니다.
- 기존 환경 변수 GEMINI_API_KEY, GEMINI_MODEL, ALLOWED_ORIGIN은 유지하세요.
- API Key를 코드나 GitHub에 입력하지 마세요.
- 실제 Gemini 부하 상황에서의 재시도 성공률과 iPad Safari 동작은 배포 후 테스트가 필요합니다.

PPT 꾸미기 기능은 이번 6.2에 포함하지 않았습니다. 별도 기획안으로 다음 버전에 반영할 예정입니다.
