O.BAKERY PROJECT 5.13 - 베이커스 퍼센트 및 토핑물 분리

설치
1. ZIP 압축을 풉니다.
2. index.html을 기존 GitHub 저장소 루트의 index.html과 교체합니다.
3. 변경 사항을 Commit하면 GitHub Pages에 반영됩니다.

변경 사항
- 재료 계량 영역에 토핑물 별도 입력 영역 추가
- 토핑물 중량은 반죽 총중량 및 반죽 베이커스 퍼센트 계산에서 제외
- 기존 밀가루 합계 100% 기준 베이커스 퍼센트 유지
- 반죽 총중량을 100%로 환산한 '총중량 대비 %' 열 추가
- 토핑물은 추가, 삭제, 복제, 순서 이동 가능
- PPTX 및 PDF 출력에 반죽 배합표와 토핑물 표 반영
- .obakery 프로젝트 저장/불러오기에 toppings 데이터 포함
- 기존 프로젝트 파일은 toppings가 없어도 정상적으로 빈 토핑 목록으로 불러오도록 호환

계산 기준
1) 밀가루 기준 % = 개별 재료 중량 / 모든 밀가루 중량 합계 × 100
2) 총중량 대비 % = 개별 반죽 재료 중량 / 반죽 재료 총중량 × 100
3) 토핑물은 위 두 계산 및 반죽 총중량에서 제외하며 별도 중량으로 표시

검증

- 중복 HTML ID 검사 통과
- 실제 iPad Safari, PowerPoint 및 PDF 인쇄 결과는 기기에서 추가 확인 필요
