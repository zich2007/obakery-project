O.BAKERY PROJECT 6.2 — 공정 순서 우선형 AI 사진 추천

이번 수정본은 기존 6.2의 AI 안정화 방식(사진 1장씩 순차 처리, 자동 재시도, 실패 사진만 재시도, 성공 결과 보존)을 유지하면서 실습 사진 workflow를 단순화했습니다.

변경된 사용 순서
1. 실습 사진 섹션의 'Gemini AI 제조공정 순서 정리'에서 공정표/실습 지시서 사진을 분석합니다.
2. AI가 추출한 JSON 결과를 직접 검토·수정한 뒤 '검토한 공정 순서 적용'을 누릅니다.
3. 적용된 공정 단계는 아래 '제조 과정 기록'에서 순서와 내용을 수정하거나 단계를 추가/삭제할 수 있습니다.
4. '실습 사진 등록 및 공정별 자동 추천'에서 실습 사진을 올리면 AI가 현재 공정 목록 안에서만 사진별 공정을 추천합니다.
5. 사진별 추천 공정을 드롭다운으로 수정하고, '검토한 사진을 공정에 배치'를 눌러 승인합니다.

주요 변경 사항
- 공정 순서 AI 창을 기존 '실습 사진' 영역으로 이동
- 공정 순서를 먼저 확정한 뒤 사진 추천을 실행하도록 변경
- 사진 추천은 사용자가 확정한 공정 단계 index/title만 사용하며, 임의의 새 공정을 만들지 않음
- 맞는 공정이 없으면 미분류로 반환하고 자동 배치하지 않음
- 중복되던 '사진으로 제조과정 기록 생성' AI workflow 제거
- 단계별 수동 사진 첨부 기능 및 PPT 공정별 사진 배치 기능 유지
- 사진별 단일 요청, 2초/5초/10초 재시도, 실패 사진만 재시도, 성공 결과 보존 유지

배포 주의
- 이 수정본은 로컬 제작본이며 GitHub/Vercel에 자동 배포하지 않았습니다.
- 기존 환경 변수 GEMINI_API_KEY, GEMINI_MODEL, ALLOWED_ORIGIN은 그대로 유지하세요.
- API Key를 코드나 GitHub에 입력하지 마세요.
- JS 문법 검사는 통과했지만, 실제 Gemini API 호출, 브라우저 UI, iPad Safari 및 PPT 출력은 아직 실기기 테스트가 필요합니다.
- 무료 등급 사진 전송 동의 안내를 유지합니다.

PPT 꾸미기 기능은 이번 수정본에 포함하지 않았습니다.


[6.3 변경 사항]
- OCR(Tesseract.js) UI, 스크립트, 관련 안내를 완전히 제거했습니다.
- 재료표/공정표 분석은 Gemini AI 또는 수동 입력으로 진행합니다.
- Gemini 일시 과부하(503), 요청 제한(429), 일시 서버 오류에 대해 5초/15초/30초 간격으로 최대 3회 재시도합니다.
- 실습 사진 순차 분석도 동일한 대기 간격을 사용합니다.
- 성공한 사진 결과 보존 및 실패 사진만 재시도 기능은 유지합니다.
- Vercel 환경 변수와 API 경로는 변경하지 않았습니다.
