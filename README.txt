O.BAKERY PROJECT 5.9
=====================

변경 사항
1. PPT 사진 원본 비율 유지
   - 사진을 지정된 상자에 강제로 자르거나 늘리지 않습니다.
   - 원본 이미지의 가로세로 비율을 읽고, 비율을 유지한 채 지정 영역 안에 맞춰 배치합니다.
   - 공정 참고 사진, 전체 실습 사진, 분류된 사진, 기타 참고 사진에 적용했습니다.

2. 재료표 이미지 위치
   - 재료표/배합표 이미지는 재료 계량 및 배합표 바로 다음 페이지에 배치합니다.
   - 맨 마지막의 일반 첨부 이미지 목록으로 보내지 않습니다.

3. 빈 재료 계량 페이지 생략
   - 재료명과 사용량이 모두 비어 있는 행은 작성되지 않은 것으로 처리합니다.
   - 유효한 재료 항목이 하나도 없으면 '재료 계량 및 배합표' 페이지를 생성하지 않습니다.

검증
- JavaScript 문법 검사 통과
- HTML 중복 ID 검사 통과
- 사진 자르기 옵션(sizingCrop) 제거 및 원본 비율 맞춤 함수 적용 확인
- 재료표 이미지의 재료 섹션 배치 확인
- 빈 재료 계량 페이지 조건부 생성 확인
- 실제 PowerPoint 렌더링과 iPad 출력은 사용자의 실제 브라우저에서 최종 확인 필요
