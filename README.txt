O.BAKERY PROJECT 5.14

변경 사항
1. PPTX와 PDF의 재료 배합표에서 '구분' 열 제거
2. 토핑물을 별도 표가 아닌 동일한 재료표 아래에 통합
   - 재료명 앞에 '토핑 ·'으로 구분
   - 토핑물은 반죽 밀가루 기준 및 반죽 총중량 대비 비율에서 제외(— 표시)
3. 표 마지막에 '반죽 총중량' 합계 행 추가
   - 총중량 대비 퍼센트 100% 표시
4. PDF 내보내기를 브라우저 인쇄 창 방식에서 PDF 파일 다운로드 방식으로 변경
   - html2pdf.js CDN 사용
   - CDN 로딩 실패 시 인쇄 저장을 대체 경로로 안내

설치
- 기존 GitHub 저장소의 루트 index.html을 이 버전의 index.html로 교체하고 commit/push 하세요.
- PDF 직접 다운로드에는 인터넷 연결이 필요합니다.

검증
- JavaScript 문법 검사 수행
- 브라우저에서 실제 PPTX/PDF 렌더링 및 iPad Safari 다운로드는 별도 실기기 테스트가 필요합니다.
