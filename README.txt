O.BAKERY PROJECT 5.10
=====================

변경 사항
1. 재료표 원본 이미지
   - 이미지 파일명/캡션 제목을 제거했습니다.
   - 이미지 1장당 PPT 한 페이지를 사용해 더 크게 표시합니다.
   - 원본 비율을 유지하며 잘림 없이 배치합니다.

2. 미입력 공란 숨김
   - 제조 공정의 작업 내용, 온도, 시간, 주의사항 중 입력된 항목만 표시합니다.
   - 입력되지 않은 항목의 '미작성', '미기록' 대체 문구를 제거했습니다.
   - 관능평가 항목은 작성된 항목만 표시하고, 한 그룹이 전부 비어 있으면 페이지를 만들지 않습니다.
   - 고찰이 비어 있으면 고찰 페이지를 만들지 않습니다.
   - 날짜가 비어 있으면 '실습 날짜 미기재' 문구를 표시하지 않습니다.
   - 재료표에서 비어 있는 재료명/사용량은 '미입력'이나 0으로 채우지 않습니다.

3. 제조과정기록의 보조 사진
   - 각 보조 사진은 한 장당 PPT 한 페이지로 구성합니다.
   - 사진은 왼쪽에 크게, 설명과 입력된 공정 조건은 오른쪽에 배치합니다.
   - 사진과 설명이 서로 다른 페이지로 분리되지 않도록 했습니다.
   - 설명은 해당 공정의 작업 내용과 추가 입력된 조건을 사용합니다.

검증
- JavaScript 문법 검사 통과
- HTML 중복 ID 검사 통과
- 공란 대체 문구 제거 확인
- 재료표 이미지 캡션 제거 확인
- 보조 사진+설명 단일 페이지 레이아웃 코드 확인
- 실제 PowerPoint 앱에서의 렌더링은 사용자 기기에서 최종 확인 필요
