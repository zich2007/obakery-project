O.BAKERY PROJECT 5.8
=====================

이번 수정
1. PPTX 생성 오류 수정
   - 기존 5.7에서 내보내기 버튼은 여전히 구형 전역변수(pptxgen)만 검사하고 있어,
     새 라이브러리 로더(ensurePptxGen)를 실제로 호출하지 않는 문제가 남아 있었습니다.
   - 이제 PPTX 생성 버튼이 라이브러리를 직접 로드한 뒤 생성자를 확인하고 PPT를 생성합니다.
   - jsDelivr → unpkg → jsDelivr GitHub CDN 순서로 재시도합니다.
   - 로드 실패 시 각 CDN 실패 사유를 표시합니다.

2. PDF 재료표 이미지 위치 수정
   - 재료표/배합표 이미지를 기타 첨부 이미지 목록에서 제외했습니다.
   - 재료 배합표 표 바로 아래에 원본 이미지가 표시됩니다.
   - PDF 출력 전에 이미지 로딩/디코딩이 끝날 때까지 기다리도록 했습니다.
   - 관능평가 및 고찰 참고 이미지는 기존처럼 뒤쪽 첨부 이미지 영역에 표시됩니다.

검증
- JavaScript 문법 검사 통과
- HTML 중복 ID 검사 통과
- PPTX 버튼에서 라이브러리 로더를 호출하는 코드 확인
- PDF 재료표 이미지 블록의 배치 확인
- 실제 브라우저 다운로드 및 iPad 출력은 배포 후 기기에서 확인 필요
