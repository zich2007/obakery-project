02제품 정보

과제의 기본 제목과 실습 품목을 입력하세요.

재료표 · 배합표 이미지 첨부직접 제작한 재료표, 배합표, 베이커스 퍼센트 정리 이미지를 등록하세요.
✨ Gemini AI 재료표 분석

재료표 사진을 AI가 직접 읽어 재료명·중량·밀가루 구분·토핑 여부를 구조화합니다. 결과는 검토 후에만 배합표에 반영됩니다.

GitHub Pages를 계속 사용할 경우 Vercel API 주소를 입력하세요. 같은 Vercel 프로젝트에서 사이트와 API를 함께 배포하면 비워두어도 됩니다.
사진을 선택하고 전송 동의 후 분석하세요.
AI가 읽지 못한 숫자나 재료는 임의로 추정하지 않습니다. 중량이 불명확한 항목은 빈 값으로 표시될 수 있으니 원본 사진과 대조하세요.
재료 계량 · 배합표 작성

재료를 직접 추가하고 사용량(g)을 입력하면 베이커스 퍼센트가 자동 계산됩니다. 모든 밀가루 항목의 합계를 100% 기준으로 계산합니다.

순서재료 구분재료명사용량 (g)베이커스 퍼센트 (%)항목 관리
등록 항목: 0개 밀가루 총량: 0 g (기준 100%) 반죽 총중량: 0 g

밀가루가 여러 종류라면 모든 밀가루 중량의 합계를 100%로 계산합니다. 각 재료의 베이커스 퍼센트는 모든 밀가루 중량의 합계를 100%로 계산합니다. 반죽 총중량의 베이커스 퍼센트도 표 마지막에 표시합니다.

토핑물 · 별도 계량

토핑물은 반죽 총중량 및 반죽 베이커스 퍼센트 계산에서 제외됩니다.

03실습 사진

반죽·공정 사진과 완성품 사진 등 과제에 사용할 이미지를 등록하세요.

실습 사진 선택 사진 수량 제한 없이 여러 장을 한 번에 선택할 수 있습니다.
선택된 사진 0장
✨ Gemini AI 제조공정 순서 정리

공정표·실습 지시서 사진을 분석해 제조공정의 순서와 작업 내용을 정리합니다. 먼저 공정 순서를 확정한 뒤, 아래에서 실습 사진을 해당 공정에 맞춰 추천받을 수 있습니다.

공정표 사진을 선택하고 전송 동의 후 분석하세요.
AI가 정리한 순서는 반드시 원본 공정표와 대조해 주세요. 사진에 없는 온도·시간·공정 설명은 만들어내지 않습니다.

✨ 실습 사진 등록 및 공정별 자동 추천

위에서 공정 순서를 먼저 적용한 다음 실습 사진을 선택하세요. AI는 확정된 공정 목록 안에서 사진별로 가장 알맞은 단계를 추천합니다. 사진은 한 장씩 순차 분석하고 실패한 사진만 재시도합니다.

공정 순서를 먼저 적용해 주세요.
AI는 현재 공정 목록 안에서만 추천합니다. 맞는 단계가 없으면 미분류로 표시되며, 사진별 추천 공정을 직접 수정한 뒤 반영하세요.

04제조 과정 기록

각 공정을 단계별로 기록하세요. 작업 내용뿐 아니라 반죽 상태, 온도, 시간, 주의사항까지 정리할 수 있습니다. 제품에 맞지 않는 단계는 삭제하고 필요한 단계는 추가하세요.

05관능평가

아래 항목을 참고해 제품을 직접 관찰하고 맛본 결과를 서술형으로 작성하세요. 예시는 작성 방향을 돕기 위한 문장이므로 제품에 맞게 수정하면 됩니다.

내부 평가

제품을 잘라 내부의 조직과 상태를 확인하고 평가합니다.

외부 평가

제품의 겉모양과 굽기 상태, 형태적 완성도를 평가합니다.

관능평가 참고 이미지 첨부단면, 기공, 외형 등 평가 내용을 뒷받침하는 사진을 등록하세요.

06고찰

제조 결과의 원인과 개선 방향을 정리하세요.

고찰 참고 이미지 첨부실패 사례, 수정 전후 비교, 실습 결과 등을 보여주는 이미지를 등록하세요.

PPTX 및 PDF로 과제를 내보낼 수 있습니다. 프로젝트 파일(.obakery)로 작성 내용을 별도 백업할 수 있습니다.
